**文枢 Wenshu** 是一款本地运行的双语论文阅读与修订软件。通过同一界面完成原文与译文对照、批注管理和修改建议审阅；导入 LaTeX 项目后，还可编辑源文件并编译预览。

面向需要阅读英文文献、整理修改意见和修订论文的研究人员、教师与学生。

## 核心功能

| 功能 | 产品说明 |
| :--- | :--- |
| **双语对照阅读** | 支持逐句、逐段中英对照，结合章节导航和专注阅读模式，方便文献精读。 |
| **PDF 原文对照** | 查看原始 PDF 页面，核对图表、公式与正文排版。 |
| **原文批注** | 针对句子或段落记录修改意见，通过批注返回对应原文。 |
| **AI 辅助改写** | 根据选中文本、批注和论文上下文生成修改建议，逐项查看修改前后的差异。 |
| **批量修订** | 根据多条批注批量生成建议，支持任务暂停、继续及逐项审阅。 |
| **LaTeX 编辑与编译** | 编辑项目副本中的源文件；审阅通过且能准确定位的修改可写入副本，再编译为 PDF。 |

界面采用浅暖灰背景、深色正文与陶土色重点标记，通过分栏布局区分阅读内容和编辑操作。

## 安装与使用

### Windows 版

1. 打开 **[版本下载页](https://github.com/feedy-hub/wenshu/releases/latest)**，下载 `wenshu-windows-*.zip`。
2. 完整解压后，双击 **`文枢.exe`** 启动。
3. 浏览器自动打开 **<http://127.0.0.1:18761/>**，导入论文即可使用。

Windows 版已包含 Python 运行环境。首次使用可选择“先用示例体验”。编译 LaTeX 项目需另行安装 TeX Live 或 TinyTeX，并将编译器加入 PATH；PDF 阅读和批注不需要 LaTeX 环境。

### 支持的文件

| 文件格式 | 导入入口 | 支持的操作 |
| :--- | :--- | :--- |
| PDF | **PDF 文档 / 导入 PDF** | 阅读、翻译、批注，生成及导出修改建议。 |
| `.tex` 文件或 LaTeX 项目 ZIP | **LaTeX 项目 / 导入论文项目** | 识别主文件、编译项目副本、编辑及修订源文件。 |
| LaTeX 项目文件夹 | **项目文件夹** | 导入主文件、图片、参考文献和模板，保留项目目录结构。 |

包含图片、参考文献或模板的项目，请导入完整文件夹或 ZIP。单独导入 `.tex` 文件不会自动导入同目录中的其他文件。文件夹导入建议使用 Edge 或 Chrome。

## 使用流程

1. **导入论文**：选择 PDF 或 LaTeX 项目，在阅读区查看正文。
2. **记录批注**：选择句子或段落，填写并保存修改要求。
3. **审阅建议**：生成修改建议，核对措辞、术语、数字与引用。
4. **应用修改**：导出建议，或将通过审阅且能准确定位的修改写入 LaTeX 项目副本，重新编译查看结果。

PDF 文件支持阅读与修改建议导出。修改源文件需要关联 LaTeX 项目；无法唯一匹配的内容需手动编辑。

## AI 服务与数据管理

### AI 服务配置

在 **“AI 服务设置”** 中填写 API 地址、模型名称与密钥。文枢支持兼容 **OpenAI Chat Completions** 的服务接口。

- **本地功能**：阅读、批注、手动编辑及差异预览无需配置 AI 服务。示例论文提供预设译文；LaTeX 编译需具备本机编译环境。
- **AI 功能**：翻译与 AI 改写需要配置服务，并将相关正文、批注及所选上下文发送至该服务。
- **密钥管理**：API 地址和模型名称保存在本机；密钥仅保存在当前程序内存中，重启后需重新填写。

生成的内容以修改建议形式保存，供用户审阅后使用。

### 本地存储与备份

论文、译文、批注、修改建议和项目副本保存在本机。Windows 版默认使用 `文枢.exe` 同目录下的 **`.data/`** 文件夹，备份或迁移时请一并保留。

关闭浏览器不会退出本地服务；再次启动文枢时会使用已运行的服务。仓库和发行包不包含个人工作记录。

## 兼容性与使用说明

| 项目 | 说明 |
| :--- | :--- |
| **操作系统** | 提供 Windows 应用下载。macOS 和 Linux 可按开发文档从源码运行；暂未提供经过运行验证的 macOS 独立应用。 |
| **PDF 文本识别** | 需要可提取的文本层，暂不支持扫描文件的 OCR 识别。复杂版式应结合原 PDF 核对。 |
| **公式显示** | 公式可通过图片显示，无法直接转换为可编辑的 LaTeX 代码。 |
| **批注版本** | 批注与对应 PDF 版本关联；重新编译后，不会自动迁移到新版本。 |
| **源文件修订** | 仅自动处理能够唯一匹配的文本。复杂宏、公式和重复内容可能需要手动编辑。 |
