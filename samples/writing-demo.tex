\begin{abstract}
Academic writing benefits from precise revision. We present a local workspace that links reading, annotation, and source editing. Every proposed change remains reviewable before it is applied.
\end{abstract}
\section{Introduction}
The system preserves the original manuscript. Readers can annotate individual sentences and inspect bilingual passages in a continuous reading view. The source document remains the authority for subsequent edits.

A translation should preserve scientific meaning. The interface places each English sentence above its Chinese translation. Figures and tables remain available in the original PDF view.
\section{Controlled Revision}
Each annotation identifies a bounded text span. A revision proposal changes only the selected span after explicit review. Neighboring sentences remain unchanged in the source copy.

The experiment includes 24 examples. This number is preserved during stylistic revision. Changes to numerical values require careful review.
\section{Limitations}
Complex mathematical expressions require additional alignment support. Ambiguous source matches are not applied automatically. Annotations remain attached to the PDF version on which they were created.
